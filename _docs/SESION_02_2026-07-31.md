## LECCIONES OPERATIVAS
- Todo cambio en wrangler.jsonc requiere rebuild antes de deploy
  (el adapter genera dist/client/wrangler.json durante el build)
- wrangler kv opera sobre KV LOCAL por defecto; usar --remote para el real
- astro dev escribe a KV simulado local, no al remoto
- Astro tiene CSRF (security.checkOrigin) activo por defecto:
  curl necesita header Origin, los navegadores no tienen el problema
- curl.exe + git-bash corrompe acentos en -F: probar con ASCII
- @astrojs/cloudflare 14.1.7: locals.runtime no disponible,
  usar import { env } from "cloudflare:workers"
- findstr.exe no lee stdin vía pipe en este entorno: usar grep sobre archivo
- No correr npm run build con el dev server levantado: corrompe caché de Vite
- PowerShell 5.1 colapsa arrays de 1 elemento: envolver en @() antes de .Count
- Al pegar código Astro en Claude Code, los tags <a de apertura pueden perderse
- Claude Code no puede distinguir un lead real de una prueba:
  usar siempre datos evidentemente falsos en pruebas
